2, 请描述下Cookie和Session区别

答案：

```yacas
Cookie 和 Session 都是存储用户信息的
Cookie位于客户端浏览器,用来存储用户不敏感信息的,Cookie任何人都可以访问,所以安全性很低,存储数据类型也受客服端限制,内存也比较小只有4k
Session位于服务器,所有信息都可以存储,而且都是经过加密,所以安全性较高,存储数据类型也是非常广的,几乎所有类型都是支持的,内存是除了服务器和应用以外都是可以使用的
```
