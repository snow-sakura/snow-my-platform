# 测试用例协作系统 - 测试指南

## 功能概述

本次更新实现了以下核心功能：

### 1. 后端改造
- ✅ 3个智能体协作：协调员(coordinator)、测试用例编写员(test_writer)、测试用例评审员(test_reviewer)
- ✅ 文件上传API：支持PDF和TXT文件解析
- ✅ SSE流式响应支持附件参数

### 2. 前端改造
- ✅ 文件上传功能：支持PDF和TXT文件，前端解析文本
- ✅ 时间轴展示：AI消息左侧显示时间轴线和彩色圆点
- ✅ 智能体标签：每个智能体有独特的图标、颜色和名称
- ✅ 折叠功能：长内容（>500字符）可折叠/展开

## 启动服务

### 后端
```bash
cd backend
./start.sh
# 或者
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 前端
```bash

```

访问：http://localhost:3002

## 测试步骤

### 测试1：基本对话功能
1. 打开浏览器 http://localhost:3002
2. 在输入框输入："帮我编写登录功能的测试用例"
3. 点击发送按钮
4. 观察消息流转：
   - 🎯 流程协调员：接收需求并分配任务
   - ✍️ 测试用例编写员：编写测试用例表格
   - 🔍 测试用例评审员：评审并提出意见
   - 🎯 流程协调员：总结最终结果

**预期结果**：
- 每条AI消息左侧显示对应智能体的彩色圆点和时间轴线
- 消息头部显示智能体图标、名称和时间
- 不同智能体使用不同颜色标识

### 测试2：文件上传功能
1. 准备一个测试用例相关的PDF或TXT文件
2. 点击输入框左侧的回形针图标
3. 选择文件（支持.pdf和.txt格式）
4. 观察附件预览区域显示文件名
5. 输入消息："请根据附件内容编写测试用例"
6. 点击发送

**预期结果**：
- 文件成功解析并显示在预览区域
- 发送后附件自动清除
- 后端接收到附件内容并拼接到用户消息中
- 智能体能够基于附件内容生成测试用例

### 测试3：长内容折叠功能
1. 发送一个会生成长回复的消息
2. 观察超过500字符的AI消息
3. 点击"收起"按钮
4. 点击"展开全部"按钮

**预期结果**：
- 长内容默认显示部分内容（150px高度）
- 底部显示"收起"按钮
- 点击后完全展开/折叠内容

### 测试4：多轮对话
1. 第一轮：发送测试用例编写请求
2. 等待对话完成
3. 第二轮：发送新的请求或针对上一轮结果提问

**预期结果**：
- 每轮对话独立进行
- 时间轴正确显示消息顺序
- 智能体标签保持一致

## 常见问题

### Q1: 文件上传失败
**原因**：文件格式不支持或文件损坏
**解决**：确保上传的是有效的PDF或TXT文件

### Q2: PDF解析乱码
**原因**：PDF包含图片或非标准编码
**解决**：尝试使用文本型PDF，或转换为TXT格式

### Q3: 智能体没有按预期工作
**原因**：可能是模型API调用失败或提示词不够清晰
**解决**：检查后端日志，查看具体的错误信息

### Q4: 时间轴显示异常
**原因**：CSS样式未正确加载
**解决**：刷新浏览器页面，清除缓存

### 网络请求检查
打开浏览器开发者工具 → Network标签：
- 查看 `/api/chat` POST请求是否成功
- 查看 `/api/stream/{session_id}` SSE连接状态
- 检查请求payload是否包含attachment字段
