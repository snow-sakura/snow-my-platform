# 快速入门指南

## 如何使用技能

当你需要生成测试用例时，只需提供你的需求文档、PRD、接口文档或其他相关材料，并明确说明：

1. **提供文档内容**
   - 直接粘贴PRD、需求说明、接口文档等内容
   - 说明你想要生成什么类型的测试用例（功能、API、性能、自动化等）

2. **可选指定模板**
   - 如果有特定的Word/Excel模板要求，提及"参考XXX模板"
   - 模板文件应放置在`assets/`目录下

## 示例用法

### 基础用法
```
根据以下PRD文档生成功能测试用例：
[在此处粘贴PRD文档内容]
```

### 指定测试类型
```
根据这个接口文档生成API测试用例：
[在此处粘贴接口文档]
```

### 参考模板
```
根据这个需求文档生成测试用例，参考assets/test-case-template.docx模板：
[在此处粘贴需求文档]
```

## 输出格式

技能将根据文档类型和要求生成结构化的测试用例，包含：
- 测试用例标识
- 测试标题和目标
- 前置条件
- 测试步骤
- 输入数据
- 预期结果
- 优先级
- 用例类型（正向/反向/边界等）

## 落盘保存

如需保存生成的测试用例到本地文件：
- 明确指示"保存到XXX路径"
- 或指定保存目录，如"写到testcases文件夹"
- 默认会保存到工作区根目录下的testcases/目录
