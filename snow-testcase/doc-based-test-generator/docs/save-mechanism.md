# 文档保存与落盘机制

## 保存行为说明

### 默认行为
- 生成的测试用例文档**直接输出在对话中**(Markdown或纯文本)
- 用户可自行复制内容，或口头要求「保存到某路径」后，由执行方使用写入工具保存到指定文件

### 主动保存
当用户说以下类似表述时，执行保存操作：
- 「保存到 xxx」
- 「存到当前项目的 docs/testcases/」
- 「写到testcases 文件夹」
- 「落地到本地」

### 文件命名规则
- 若用户只指定了目录未指定文件名，采用格式：`测试用例_<模块或文档简称>_<日期>.md`
- 日期格式为：YYYYMMDD（如：20241201）
- 例如：`测试用例_用户登录模块_20241201.md`

### 默认落盘目录
- 若用户未指定路径但希望落盘，默认保存到**当前工作区根目录下的testcases/**目录
- 若该目录不存在则先创建再写入
- 文件名同上所述规则

### 注意事项
- **不自动执行写盘**：除非用户明确要求保存或指定了路径，否则不主动调用写入工具，仅输出在对话中
- 保存前会再次确认内容的完整性
- 支持多种格式的保存（.md, .txt, 以及其他根据用户需求的格式）
